# Code of conduct

## The short version

Be straight with people. Assume the other person is trying to get the rule
right. Disagree about the regulation as much as you like, and about each other
not at all.

## What is expected

- Say what you checked and how, so someone can check it themselves
- Correct yourself in the open when you are wrong, with the superseded claim
  still visible
- Take a correction the same way, without making it about the person giving it

## What is not

Harassment, personal attacks, or sustained disruption. Publishing anyone's
private information. Any conduct that would be out of place between colleagues.

## Scope

This applies wherever someone is representing the project. The issue tracker
and pull requests are the whole of that today.

## Enforcement

Report conduct to the maintainer through
[a private security advisory](https://github.com/KvashaIhor/originshift/security/advisories/new),
which is the only private channel this repository has. One maintainer reads it.
Reports are handled discreetly, and the outcome may be a warning, removal of
content, or a block.

I am one person. Saying that plainly beats implying a committee.
